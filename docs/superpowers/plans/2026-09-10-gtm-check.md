# Incrément 1 — Check santé du tag manager (`feat/gtm-check`)

> **Pour les workers agentiques :** SOUS-SKILL REQUISE — `superpowers:subagent-driven-development` (recommandé) ou `superpowers:executing-plans` pour exécuter ce plan tâche par tâche. Les étapes utilisent des cases (`- [ ]`).

**Objectif :** analyser statiquement le HTML d'un site pour détecter la configuration de Google Tag Manager et repérer/expliquer la classe de problème « GTM installé mais le mode prévisualisation ne s'y connecte pas ». Aucune IA.

**Architecture :** un fetch HTTP léger (`fetch_page`) → un analyseur pur (`analyze_gtm`) → câblé dans `run_audit` sur le motif `tls_checker` existant (callable injectable, `None` = skip). Les findings sévères deviennent des issues `TRACKING` dans le backlog. Le bloc `gtm` remonte dans `GET /websites/{id}/audit` et s'affiche sur `/audit`.

**Tech Stack :** Python 3.12 / FastAPI async, `httpx` (+ `httpx.MockTransport` en test), SQLAlchemy 2.0, pytest `-W error` ; Next.js 16 / React 19, `react-markdown` non requis ici.

**Spec :** `docs/superpowers/specs/2026-09-10-advisor-agent-gtm-check-design.md` (§3, §4).

## Contraintes globales (rappel spec)

- **Lecture seule.** `analyze_gtm` est pur ; `fetch_page` fait un seul GET, `follow_redirects=True`, timeout 8 s, User-Agent `ControlCenterBot/1.0`, corps tronqué à 400 000 octets.
- **Ne jamais lever** hors de `analyze_gtm` : `check_gtm` attrape tout et renvoie un `GtmCheck` avec `error` renseigné et `findings=()`.
- **Motif projet** : callable injectable via `deps.py` (`get_gtm_checker`), `Annotated[..., Depends(...)]`, override en test via `app.dependency_overrides`. En mode `google_oauth_mock`, `get_gtm_checker` renvoie un skip (`_skip_gtm`) — les domaines de démo n'ont pas de vrai site à sonder (comme `get_stack_detector`).
- **`run_audit(gtm_checker=None)` par défaut** → seed dev et tests unitaires ne sondent rien.
- **Pas de migration.** `IssueCategory.TRACKING` existe déjà.
- **ruff** `select = ["E4","E7","E9","F","W","I","UP","B","C4","SIM","PLC","PLE","PLW","RUF"]`, `line-length = 100`. `ruff format` **non** vérifié en CI — ne pas reformater de fichiers hors périmètre.
- **Front** : `next build` + `eslint --max-warnings 0` = garantie de non-régression (pas de tests unitaires front).
- Commits fréquents, un par tâche terminée.

```python
"""Fetch HTTP léger partagé : un GET, en-têtes aplaties, redirections tracées.

Sert la détection de stack et le check GTM. `fetch_page` peut lever
`httpx.HTTPError` — les appelants (ex. `check_gtm`) décident quoi en faire.
"""

from __future__ import annotations

from collections.abc import Mapping
from dataclasses import dataclass

import httpx

_TIMEOUT = httpx.Timeout(8.0)
_MAX_BYTES = 400_000
_UA = "ControlCenterBot/1.0"


@dataclass(frozen=True, slots=True)
class PageSnapshot:
    url: str
    final_url: str
    status: int
    html: str
    headers: Mapping[str, str]
    redirected: bool
    history: tuple[tuple[int, str], ...]


async def fetch_page(
    url: str,
    *,
    allow_insecure: bool = False,
    client: httpx.AsyncClient | None = None,
) -> PageSnapshot:
    owns_client = client is None
    http = client or httpx.AsyncClient(
        timeout=_TIMEOUT,
        follow_redirects=True,
        headers={"User-Agent": _UA},
        verify=not allow_insecure,
    )
    try:
        response = await http.get(url)
    finally:
        if owns_client:
            await http.aclose()

    history = tuple(
        (hop.status_code, hop.headers.get("location", "")) for hop in response.history
    )
    return PageSnapshot(
        url=url,
        final_url=str(response.url),
        status=response.status_code,
        html=response.text[:_MAX_BYTES],
        headers={k.lower(): v for k, v in response.headers.items()},
        redirected=bool(response.history),
        history=history,
    )
```

**Règles de détection** (le détail exact des regex est laissé à l'implémentation, contraint par les tests ci-dessous) :

| code finding | sévérité | déclencheur |
|---|---|---|
| `gtm_preview_csp_block` | high | CSP présente (en-tête `content-security-policy` ou `<meta http-equiv>`) **et** `googletagmanager.com` absent de `script-src`/`connect-src`/`default-src` |
| `gtm_consent_gated` | medium | le `<script>` chargeant `gtm.js` (ou contenant `GTM-`) porte `type="text/plain"` / `data-cookieconsent` / `data-cookiecategory` / classe `optanon-category` |
| `gtm_custom_datalayer` | medium | nom de data layer ≠ `dataLayer` (5ᵉ arg du snippet `(function(w,d,s,l,i)…'…','GTM-'` ou `&l=` dans l'URL `gtm.js`) |
| `gtm_multiple_containers` | medium | ≥ 2 identifiants `GTM-…` distincts |
| `gtm_noscript_only` | medium | `googletagmanager.com/ns.html` présent mais aucun `gtm.js` |
| `gtm_snippet_not_in_head` | low | `gtm.js` présent mais après `</head>` |
| `gtm_server_side` | low | hôte du `src` de `gtm.js` ≠ `www.googletagmanager.com` |
| `ga4_hardcoded_alongside_gtm` | low | `googletagmanager.com/gtag/js` présent **et** au moins un conteneur `GTM-` |
| `gtm_query_stripped` | low | `page.redirected` et un hop de `history` a une `location` sans `?` |

`snippet_form` : `standard` si `googletagmanager.com/gtm.js` ; sinon `custom_loader` si un `GTM-` est présent ; `noscript_only` si seul `ns.html` ; `absent` si aucun `GTM-`. `snippet_in_head` : `None` si `absent`, sinon position de `gtm.js` (ou du 1ᵉʳ `GTM-`) avant `</head>`. `consent_platform` : première signature CMP trouvée parmi `onetrust` (`otSDKStub`, `optanon`), `cookiebot` (`cookiebot`, `data-cbid`), `axeptio`, `didomi`, `tarteaucitron`, `complianz` (`cmplz`), `cookieyes`, `osano`, `klaro`. `csp_allows_gtm` / `csp_blocks_preview` : `None` si pas de CSP.

"""Analyse statique de la configuration Google Tag Manager d'une page.

`analyze_gtm(page)` est pur. `check_gtm(domain)` enrobe le fetch et ne lève
jamais (renvoie `GtmCheck(error=...)` en cas d'échec réseau).

import re
from dataclasses import dataclass, field
from datetime import UTC, datetime
from typing import Literal

from app.services.page_fetch import PageSnapshot, fetch_page

Severity = Literal["low", "medium", "high"]

_CONTAINER_RE = re.compile(r"GTM-[A-Z0-9]{4,}")
_GA4_RE = re.compile(r"G-[A-Z0-9]{6,}")
_DL_SNIPPET_RE = re.compile(
    r"\(window,\s*document,\s*['\"]script['\"],\s*['\"]([^'\"]+)['\"],\s*['\"]GTM-"
)
_DL_URL_RE = re.compile(r"gtm\.js\?[^\"']*[&?]l=([A-Za-z0-9_]+)")
_GTM_JS_SRC_RE = re.compile(r"src=[\"']https?://([^/\"']+)/gtm\.js")
_GTM_SCRIPT_TAG_RE = re.compile(r"<script\b[^>]*gtm\.js[^>]*>", re.IGNORECASE)
_CSP_META_RE = re.compile(
    r"<meta[^>]+http-equiv=[\"']content-security-policy[\"'][^>]+content=[\"']([^\"']+)[\"']",
    re.IGNORECASE,
)

_CMP_SIGNATURES: tuple[tuple[str, tuple[str, ...]], ...] = (
    ("onetrust", ("otsdkstub", "optanon", "onetrust", "cookielaw.org")),
    ("cookiebot", ("cookiebot", "data-cbid", "consent.cookiebot")),
    ("axeptio", ("axeptio",)),
    ("didomi", ("didomi",)),
    ("tarteaucitron", ("tarteaucitron",)),
    ("complianz", ("cmplz", "complianz")),
    ("cookieyes", ("cookieyes",)),
    ("osano", ("osano",)),
    ("klaro", ("klaro",)),
)

_CONSENT_GATE_HINTS = ("type=\"text/plain\"", "type='text/plain'", "data-cookieconsent",

    title: str

    csp_present: bool = False
    csp_allows_gtm: bool | None = None

    server_side: bool = False
    query_stripped_on_redirect: bool = False

def _csp_value(page: PageSnapshot) -> str | None:
    header = page.headers.get("content-security-policy")

    meta = _CSP_META_RE.search(page.html)
    return meta.group(1).lower() if meta else None

Points d'implémentation :
- `snippet_in_head` : `pos = low.find("gtm.js")` (ou 1ᵉʳ `GTM-`), `head_end = low.find("</head>")` ; `None` si `snippet_form == "absent"`.
- `data_layer_name` : `_DL_SNIPPET_RE` puis `_DL_URL_RE`, défaut `"dataLayer"`.
- `gtm_consent_gated` : chercher le tag `<script … gtm.js …>` via `_GTM_SCRIPT_TAG_RE` et tester la présence d'un `_CONSENT_GATE_HINTS` dedans ; sinon, un bloc `<script>` inline contenant `GTM-` avec `type="text/plain"`.
- `consent_platform` : 1ʳᵉ signature `_CMP_SIGNATURES` trouvée dans `low`.
